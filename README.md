# Cc Skill Security Review

Use this skill when adding authentication, handling user input, working with secrets, creating API endpoints, or implementing payment/sensitive features. Provides comprehensive security checklist and patterns.

## Overview

This repository contains the AITMPL skill definition and all companion files published with it.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-security-review-skill.git ~/.claude/skills/cc-skill-security-review
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-security-review` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/cc-skill-security-review` when appropriate.
